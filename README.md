# 🥩 한토막 (Han Tomac) - 스테이크 전문점 홍보 홈페이지

> **성신여대 스테이크 맛집 '한토막'의 홍보를 위해 친구와 협업하여 제작한 웹 사이트입니다.**  
> 당시 아르바이트를 하던 가게를 직접 홍보하기 위해 기획부터 배포까지 진행한 의미 있는 프로젝트입니다.

---

## 📅 프로젝트 정보
- **작업 기간**: 2021. 03 ~ 2021. 06 (약 3개월)
- **인력 구성**: 2명
  - **조동휘 (Cho)**: Backend 개발, 서버 구축 및 배포
  - **이동건 (Lee)**: Frontend 개발, UI/UX 디자인
- **프로젝트 목적**: 아르바이트 중인 스테이크 전문점의 온라인 홍보 및 정보 제공

---

## 🛠 사용 언어 및 개발 환경
- **Backend**: `Python`, `Flask`
- **Frontend**: `HTML5`, `CSS3`, `JavaScript`, `Bootstrap`
- **Deployment**: `Netlify` (상시 운영 배포), 기타 웹 서버

---

## 🚀 주요 업무 및 상세 역할

### 1. Backend (조동휘)
- **Flask Framework**를 활용한 웹 서버 로직 구현
- 동적 페이지 렌더링 및 프론트엔드와의 데이터 연동
- 운영 비용 최소화 및 상시 접속을 위한 배포 프로세스 관리

### 2. Frontend (이동건)
- **Bootstrap** 프레임워크 기반의 반응형 레이아웃 설계
- 스테이크 메뉴의 시각적 요소를 강조한 UI 디자인
- 사용자 편의를 고려한 웹 페이지 구조 설계

---

## 🔗 프로젝트 특징 및 비하인드
- **실제 서비스 운영**: 제작 완료 후 실제 인터넷 서비스에 배포하여 운영하였습니다.
- **네이버 지도 연동**: 한때 성신여대 맛집으로 검색 시 네이버 지도 링크에 해당 홈페이지가 등록되어 실제 홍보 수단으로 활용되었습니다.
- **현재 상태**: 아쉽게도 현재는 해당 가게(한토막)의 폐업으로 인해 사이트 접속이나 서비스 확인은 어렵지만, 개발자로서의 첫 협업과 배포의 경험을 준 소중한 프로젝트입니다.

---

## 💡 느낀 점
- **웹 개발의 접근성**: 직접 프론트엔드와 백엔드를 모두 다뤄보며 웹 개발이 생각보다 쉽게 접근할 수 있는 영역임을 깨달았습니다.
- **협업의 가치**: 친구와 역할을 나누어 하나의 완성된 서비스를 만들어가는 과정에서 소통과 역할 분담의 중요성을 배웠습니다.
- **배포의 경험**: 로컬 환경을 넘어 실제 유저가 접속할 수 있는 환경을 구축하며 서비스 운영에 대한 자신감을 얻었습니다.
